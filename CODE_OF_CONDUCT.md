# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't welcome in issues, pull requests or discussions.

Report problems privately through the repository's **Security** tab (Report a vulnerability) and say it's a conduct report. Reports are kept confidential. Maintainers may remove comments, lock threads or block accounts that break these rules.
