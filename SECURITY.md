# Security policy

This repository holds prompts, a SillyTavern preset and a theme; none of it runs code. Report anything that could still put users at risk, such as a preset setting that sends data somewhere unexpected or CSS in the theme that loads remote content, privately through the repository's **Security** tab (**Report a vulnerability**), not in a public issue.

You'll get a reply within a week. Only the latest version on `main` is maintained.
